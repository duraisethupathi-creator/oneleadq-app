# OneLeadQ App

OneLeadQ Digital Marketing Agency Command Center.

## Stage 1
React Native + Expo + TypeScript foundation with premium green/gold UI, Dashboard, Clients and bottom navigation.

## Run
```bash
npm install
npx expo start
```
Scan the QR code with Expo Go on Android.

> AI/API integrations are intentionally deferred to a later stage. Never commit API keys or client secrets.
